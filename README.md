# The Repo

Our Repo contains 3 Lens Studio Projects designed for use with the snap spectacles, each with their own educational pursuits.

## SolarSecrets
Solar Secrets is our main submission for the MIT Reality Hack at AWE 2026. It is an interactive gamified and AI-Assisted learning experience that revolves around our Solar System where the Solar System (literally) revolves around the user! Learners will see planets in our solar system revolving around them. A virtual dart will be present for learners to throw towards planets. A successful hit unlocks an AI-generated fact about the target planet. AI can also be disabled to display one of three facts about each planet at random.

## Interactive Cube
The interactive cube requires two hands to resize the cube. As this happens the respective volume equation changes. It would make more sense for a shape with different dimensions like a rectangle, but for now. . .we have a cube.

## Presentation Deck
This presentation deck allows for an approach to more portable learning, possibly used as flashcards for spaced-repetition learning on the go. AI can eventually be integrated to potentially create flash card content based on provided topics.
